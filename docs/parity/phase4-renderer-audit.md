## Comparison tool baseline

Before edits, `node scripts/parity/compare-renderer-strings.mjs` reported 383 strings only in 3.2.0 and 350 only locally. After the guide and Help ports and final build, it reports 295 only in 3.2.0 and 284 only locally. Its parser includes minified code fragments (for example `&&se.depth<re?`), so these counts are leads, not a list of confirmed UI differences. The remaining human-readable text is held pack/plans copy; guide text no longer appears in either difference list.
