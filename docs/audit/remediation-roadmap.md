# Remediation roadmap

The following sequence is for approval. Start each defect with a failing executable reproducer, capture its RED result, then apply the smallest root-cause change and run the same case to GREEN. Keep one file owner and independently review boundary changes. Both OSes need relevant branch checks and physical verification where the behavior depends on hardware or Electron.

| Order | Proposed work | Acceptance evidence |
|---|---|---|
| 1 | Isolate Direct Assist history and in-flight requests at fresh session reset. Preserve explicit resume. [AUD-UI-001](electron-findings.md#aud-ui-001--fresh-session-reset-leaves-direct-assist-history-populated), [AUD-UI-002](electron-findings.md#aud-ui-002--direct-assist-request-ownership-can-survive-the-session-reset-event). | Fresh history is empty. Resume restores only its saved turns. Delayed old tokens/done cannot mutate the new session or block its answer. |
| 2 | Reject stale Deepgram finals and endpoints, then reproduce the local worker tail case. [AUD-STT-001](transcription-findings.md#aud-stt-001--retired-deepgram-connection-can-emit-finals-and-endpoints), [AUD-STT-002](transcription-findings.md#aud-stt-002--local-final-inference-can-outlive-the-meeting-snapshot). | Fake connection replay accepts only current events. Local final is persisted before snapshot or reported incomplete at a bounded deadline. |
| 3 | Fix scoped vector recall and test short elliptical follow-ups. [AUD-PER-001](performance-findings.md#aud-per-001--native-vector-search-can-return-empty-while-matching-meeting-evidence-exists), [AUD-QST-001](question-detection-findings.md#aud-qst-001--a-short-elliptical-question-can-be-filtered-before-the-judge). | Real sqlite-vec fixture retrieves eligible rank beyond global overfetch. Punctuation-free questions reach the judge without admitting backchannels indiscriminately. |
| 4 | Separate lifecycle readiness and durability, then narrow restart admission to resource ownership. [AUD-SES-001](session-management-findings.md#aud-ses-001--restart-waits-on-the-previous-sessions-full-teardown-chain), [AUD-SES-002](session-management-findings.md#aud-ses-002--stop-success-does-not-report-placeholder-save-failure). | Delay native teardown, DB save and optional indexing independently. Prove no shared resource reuse, bounded restart behavior and visible save recovery. |
| 5 | Make effective device/provider and missing-context outcomes observable. Review authorized Direct surfaces and stream completion. [AUD-AUD-001](audio-pipeline-findings.md#aud-aud-001--native-capture-can-drop-pcm-without-a-gap-signal), [AUD-AUD-002](audio-pipeline-findings.md#aud-aud-002--windows-fallback-follows-the-default-output-instead-of-a-pinned-endpoint), [AUD-STT-003](transcription-findings.md#aud-stt-003--missing-selected-credentials-change-the-effective-provider), [AUD-AI-001](ai-orchestration-findings.md#aud-ai-001--direct-context-read-failure-bypasses-the-trim-notice), [AUD-AI-002](ai-orchestration-findings.md#aud-ai-002--a-provider-can-keep-a-committed-stream-open-with-frequent-content), [AUD-ELC-001](electron-findings.md#aud-elc-001--direct-ipc-checks-sender-identity-without-establishing-surface-ownership). | Fault injection shows overflow/route/error status, preserves privacy policy, and yields correlated terminal state and verified resource closure. |
| 6 | Turn focused cases into enforcing macOS and Windows coverage. Run measured replay and native soak before performance changes. [AUD-TST-001](testing-gaps.md#aud-tst-001--default-browser-smoke-configuration-does-not-establish-electron-ipc), [AUD-TST-002](testing-gaps.md#aud-tst-002--broad-windows-electron-failures-can-leave-the-ci-job-green), [AUD-TST-003](testing-gaps.md#aud-tst-003--integrated-dual-channel-fault-replay-and-native-soak-coverage-was-not-established), [AUD-PER-002](performance-findings.md#aud-per-002--synchronous-vector-fallback-can-delay-main-process-work), [AUD-PER-003](performance-findings.md#aud-per-003--growing-recovery-snapshots-serialize-on-the-main-thread). | CI executes the real preload and focused Windows suites. Benchmark before and after on the same synthetic datasets, with correct transcript and answer output. |

Measure live latency and loss before setting acceptance budgets. For packaged verification, exercise install, permission denial/regrant, device changes, interrupted network, restart and quit on both operating systems. Use sanitized replay inputs and local fake providers for deterministic gates. Repeat the release smoke against physical capture and authorized live providers separately.
